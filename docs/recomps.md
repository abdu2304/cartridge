# Recomps

The researched catalogue of 96 recomps (0.9.65 to 0.9.69) was retired in 0.9.70 at the owner's request: recomps are now
a curated list of Cartridge Verified recipes, added one game at a time. See `docs/recipes.md`. Recomps installed from
the old catalogue are kept and shown as Unverified; the old entries are in git history (`electron/recomps.json` before
0.9.70).
