## Cartridge 0.9.85 · PC Ports

### New
- **PC Ports, laid out like a console.** The Steam card in Consoles is now called PC Ports. It opens a page of the ports you have installed, as game cards with your library's covers. Pressing one opens that game's own page, with its picture, summary and play time. There the main button is Play the PC Port, or Set Up the PC Port (or Update) when it isn't ready yet.
- **PC ports in Continue Playing.** A port's play time from Steam now counts for the game it came from, so a port you played shows up in Continue Playing on Home and in Start's Continue tile, marked PC Port. Opening it from there plays the port again.

### Changed
- **Getting, updating and setting up ports lives in Settings → Emulators → PC Ports** (it was called Recomps). The PC Ports page's Get and Manage button (X) takes you there, and so does Get PC Ports when you have none yet.
- **"Recomp" is called "PC Port" everywhere it shows**, including the game page's More and the Achievements console list.
- **A port from a GitHub link that's ready starts straight from its game page**, instead of opening its sheet.
