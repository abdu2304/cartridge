## Cartridge 0.9.93 · Launch Check

### New
- **Launch Check before Play.** When something would stop a game from starting, Play now says what it is before anything opens, instead of a black screen or an emulator error. Each problem has its fix on the same line: Add to Steam, Allow Access for a Flatpak emulator that can't see your games folder, Get It from RomM for a missing BIOS, Download It Again when the game's files have gone, Get an Emulator when none is installed for that console, and more. Fix it there, or press Play Anyway. When nothing is in the way, Play works exactly as before, with no extra step.
- **PC ports are checked too.** Your copy of the game, Proton for Windows builds, the port's setup and its Steam shortcut.
- **Launch Check in a game's More.** See what Cartridge checks for any installed game, whenever you like.

### Fixed
- **Nightly and Beta builds are made again.** They had stopped since 0.9.71 because a file the build needs was never added.
